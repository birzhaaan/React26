Solutions for all topics + final task.

1. Variables and Data Types


  

    let can be reassigned, const cannot — but if a const holds an object or array, its contents can still be changed, only the reference itself is locked. typeof null returns "object", which is a long-standing bug in JS since null is not actually an object. The primitive types in JS are string, number, boolean, undefined, null, symbol and bigint.
  






  
2. Arrays

  

  

    map, filter, find, reduce and includes are all non-mutating array methods — each one returns a new value (a new array, a single item, or a number) instead of changing the original array. That's why the numbers array stays [3, 7, 2, 10, 5] after all the operations.
  






  
3. Arrays of Objects

  

  

    The passing threshold wasn't specified in the task, so grade 60 or higher was assumed. reduce is used twice here: once to find the top student by comparing pairs, and once to calculate the average by summing then dividing — a common pattern for collapsing an array into a single value.
  






  
4. Objects

  

  

    Direct property access, like user.age = 23 or delete user.address.street, mutates the object in place. Destructuring just reads values into new variables and does not change the object at all. Renaming a variable during destructuring and reaching into nested objects both follow the same shape-matching rule as regular object literals.
  






  
5. Values and References

  

  

    Objects are assigned by reference, so copy and original point to the same object in memory — changing one is visible through the other. Spreading an object creates a new top-level object, so primitive fields like score are copied independently. But spread only copies the first level: a nested object like address is still a reference to the same object, so changing its city through the copy changes the original too. To copy deeply, use structuredClone or spread the nested object manually.
  






  
6. Functions

  

  

    A function declaration is hoisted, so it can technically be called before it appears in the file. An arrow function is just a value assigned to a variable — it isn't hoisted, and it doesn't have its own this or arguments, which starts to matter once we get to React components and callbacks.
  






  
7. Functions as Values

  

  

    Functions in JS are first-class values: they can be stored in variables, passed as arguments, and returned from other functions. Writing "add" refers to the function itself, so it can be passed around and called later. Writing "add()" calls the function immediately and gives you the result of running it.
  






  
8. Scope

  

  

    Global scope means a variable is available throughout the whole file or program. Function scope means a variable is only visible inside the function where it was declared, which is how var behaves. Block scope means a variable is only visible inside its own curly-brace block, which is how let and const behave. var also ignores blocks entirely and gets hoisted, while let and const stay in a "temporal dead zone" until the line where they're declared.
  






  
9. Closure

  

  

    The inner function remembers the scope it was created in, even after the outer function has already finished running. That's a closure: the count variable isn't removed from memory as long as the inner function still holds onto it.
  






  
10. Destructuring, Spread and Rest

  

  

    Spread unpacks the elements of an array or object outward, which is useful when building a new array or object or when passing arguments. Rest does the opposite — it gathers an arbitrary number of arguments or elements into a single array, which is used in function parameters or during destructuring.
  






  
11. Optional Chaining and Nullish Coalescing

  

  

    Without optional chaining, accessing a property like city on a missing address throws a TypeError. Optional chaining simply returns undefined instead of throwing. The || operator triggers on any falsy value, including 0, an empty string and false, so it can replace values you actually wanted to keep. The ?? operator only triggers on null or undefined, which makes it safer when zero or an empty string are valid values.
