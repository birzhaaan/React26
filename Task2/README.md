# About Me — React SPA

A personal "About me" page built with React and Vite for the KBTU React course.

## Components

- `Header` — navigation
- `Hero` — name, photo and short intro
- `About` — about me section
- `Skills` — list of skills
- `Contact` — contact links
- `Footer`

All personal data is stored in `src/data.js`.

## Run locally

npm install
npm run dev

## Deploy

npm run deploy

The site is deployed to GitHub Pages with the `gh-pages` package.
